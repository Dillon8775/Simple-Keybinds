# Version 1.4.9
- Added Debug GUI Scale keybind, unbounded by default.
- Renamed "Simple Scroll Keybinds" category to "Simple Hold n' Scroll Keybinds".
- Renamed "Change *setting*" keybinds to just *setting*.
  - Ex: renamed "Change Master Volume" keybind -> "Master Volume".
- Scrolling keybinds only work when the player is not in a screen.


- Changed default Toggle Fog keybind to ALT + F *(f makes more sense for fog)*.
- Changed default Master Volume keybind to ALT + M *(since alt is closer to the M key)*.
- Changed default Brightness keybind to B.
- Changed default Toggle Chunk Borders keybind to ALT + B *(b makes more sense for chunk boundaries, using alt here because brightness now uses b key).*
- Changed default Render Distance keybind to R.
- Renamed Toggle Chunk Borders keybind to Toggle Chunk Boundaries.
- Unbounded Entity Distance keybind by default.
- Unbounded FOV keybind by default.


- Added missing translations.
- Fixed redundant key conflicts.
