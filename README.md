## Compatible with any Minecraft version above (or of) 1.16.5.

### This mod various different simple keybinds to the game:
- A fog keybind, which enables/disables fog.
- A fullbright keybind, which sets the users gamma to 1,200% (basically _fullbright_) and back to 100%.
- A simple key to toggle chunk borders, hitboxes, advanced tooltips, HUD overlay, F3/debug menu, and clear chat.
- A simple key to reload all chunks, increase/decrease brightness, and pause without menu.
