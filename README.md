# Adds various different "Simple Keybinds" to the game.

### Currently compatible with Minecraft versions above 1.20-1.21.8 (fabric).

---

**You *can* use this mod with Forge/NeoForge! But, you must download the following mods. Note that OptiFine does not work with this installed.**
#### ***Only compatible on Minecraft 1.20.1, 1.21, and 1.21.1.***

**[Sinytra Connector](https://modrinth.com/mod/connector)** - A translation/compatiblity mod that allows running Fabric mods on NeoForge/Forge.

**[Forgified Fabric API]()** - Fabric API, but for Forge.

---
## KEYBINDS:
- #### A fog keybind, which enables/disables fog (Default Key = **O**)
- #### A fullbright keybind, which sets the users gamma to 1,200% (basically _fullbright_) and back to 100%/the previous brightness. (Default Key = **V**)
- #### Toggle chunk borders (Default Key = _B_)
- #### Hitboxes (Default Key = _X_)
- #### Advanced Tooltips (_No default key assigned._)
- #### HUD Overlay (_No default key assigned._)
- #### Clear chat (_No default key assigned._)
- #### Reload all chunks (_No default key assigned._)
- #### Pause without menu (_No default key assigned._)

## SCROLLING KEYS:
### To use these keys, hold down the assigned key and use your mousewheel to increase/decrease the setting:
- #### A key to change render distance (Default Key = _U_)
- #### A key to change the master volume (Default Key = *M*)
- #### A key to change entity distance (Default Key = _H_)
- #### A key to change brightness (Default Key = _J_)
